
# AC Monitor

A Windows desktop application for monitoring Ancient Conquer game activity.

## Features

- Game client detection and selection
- Multiple character monitoring
- OCR-based death detection
- Chat message monitoring
- Configurable chat area coordinates
- Death alert history
- Chat log history
- Notification integration placeholders
- Configurable OCR and application variables

## Requirements

- Windows 10/11
- Python 3.14 (64-bit)
- Tesseract OCR
